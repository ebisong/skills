# Skills

Agent skills I built for my own work. They run in Claude Code, Codex, Cursor, and any agent that reads `SKILL.md` files.

I'm Eban, a founding engineer turned founder. Most of what I build these days helps engineers get from "it works" to "people pay for it." A skill lands here once I've used it enough to trust it.

## Install

**Claude Code** (updates when I ship)

```
/plugin marketplace add ebisong/skills
/plugin install skills@ebisong
```

**Any agent** (editable copies in your repo)

```bash
npx skills add ebisong/skills
```
